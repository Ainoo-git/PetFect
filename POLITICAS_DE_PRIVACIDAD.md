# Política de Privacidad – PetFect

Última actualización: mayo 2026

## 1. Datos recopilados
- Email del usuario
- Nombre de usuario
- Imágenes subidas
- Publicaciones realizadas
- Identificador de dispositivo (Firebase)

## 2. Finalidad
Los datos se utilizan para:
- Autenticación
- Publicación de mascotas
- Comunicación entre usuarios

## 3. Almacenamiento
- Firebase Authentication
- Cloud Firestore
- Supabase Storage

## 4. Derechos del usuario
El usuario puede solicitar:
- Acceso a sus datos
- Modificación
- Eliminación total

## 5. Conservación
Los datos se conservan mientras la cuenta esté activa.

## 6. Seguridad
Se aplican medidas técnicas razonables de protección.

## 7. Contacto
Aplicación académica sin servicio comercial.
